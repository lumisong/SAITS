# Local Workspace

This folder contains local experiment materials separated from upstream source.

## Sections

- `docs/`: local notes and workspace guides.
- `reports/`: generated experiment reports.
- `configs/`: custom experiment configs.
- `dataset_scripts/`: custom dataset scripts/notebooks.
- `scripts/`: local run scripts.
- `sandbox/`: temporary test files.
- `assets/`: local assets.
- `data/`: raw/processed data.
- `artifacts/`: training/testing outputs.

## First Steps

1. Read `docs/WORKSPACE_STRUCTURE.md`.
2. Open `docs/REPORTS.md`.
